# das-news-bot ✨

Telegram-бот для автоматической публикации статей из двух духовных сайтов: [harekrishna.ru](https://harekrishna.ru/) и [sridharmaharaj.ru](https://sridharmaharaj.ru/).

## Функционал
- Рассылка статей 2 раза в день (в 11:00 и 17:00 по Томскому времени), с чередованием источников.
- Парсинг текста и превью-картинки из статей.
- Обработка ссылок, скинутых в чат: бот парсит статью и постит в Telegram-канал.
- Авто-обрезка заголовка (удаляется англ. часть после |).
- Подставка случайных заголовков-заглушек, если статья без имени.

## Установка
```bash
pip install -r requirements.txt
python DAS.py
```

## Переменные
- `BOT_TOKEN` — Telegram API Token
- `CHANNEL_ID` — целевой телеграм-канал

## Зависимости
```txt
requests
python-telegram-bot
beautifulsoup4
apscheduler
pytz
```

## Пользователь
Бот написан для миссии Шри Чайтанья Сарасват Матх в Томске, но может быть подключен к любому каналу с духовными целями.
